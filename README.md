# vet-skill setup (Windows)

Step-by-step guide to add a `vet-skill` skill to Claude Code on Windows. It checks a Claude Code skill, plugin, or agent repo before you install it.

- Checks that the repo exists and matches what the post claims.
- Reads the real files and scans them for risky behavior.
- Compares against the skills you already have.
- Gives one verdict per skill. It never installs anything without your yes.

## What is in here

- `install-vet-skill.md`: the guide, including the full `SKILL.md` to paste in. Start here.

## Limits

- Review only. A clean verdict means no red flags found, not a guarantee.
- Written October 2026 on Windows 11. Commands may have changed since.
- Windows only.
